# Datasets

The portfolio examples use datasets bundled with scikit-learn, so they run without separate downloads:

- **Iris** — three flower species; introductory classification.
- **Breast Cancer Wisconsin** — diagnostic feature table; binary classification for learning only, not medical use.
- **Wine** — chemical measurements for wine-class classification.

## Suggested next datasets

- UCI Machine Learning Repository: https://archive.ics.uci.edu/
- OpenML: https://www.openml.org/
- Kaggle Datasets: https://www.kaggle.com/datasets

Before using an external dataset, review its license, provenance, privacy risks, target leakage, missing values, and permitted use. Keep large data files and secrets out of Git unless their license and repository size make that appropriate.
